# АСТ «GranD» — Ансамбль современного танца (г. Караганда)

Современный, конверсионный и интерактивный лендинг нового поколения, разработанный взамен шаблонного Taplink.

## 🚀 Что было улучшено по сравнению с оригинальным Taplink:

1. **Дизайн мирового уровня (Dark Luxury Stage UI):**
   - Глубокая сценическая тема с неоновыми фиолетовыми и розовыми акцентами в фирменном стиле коллектива.
   - Микроанимации, стеклянный морфизм (glassmorphism), адаптивная бегущая строка с УТП.
2. **Интерактивный Квиз (подбор группы за 30 секунд):**
   - Интеллектуальный расчет группы по возрасту ребенка (5-7 лет, 8-11 лет, 12-16 лет), уровню подготовки и танцевальным предпочтениям.
   - Мгновенная выдача рекомендованной группы, имени тренера и генерация готовой персональной заявки в WhatsApp.
3. **Команда педагогов с реальными фото:**
   - Вместо одинакового шаблонного описания — оформленные карточки каждого наставника со специализацией (Главный балетмейстер, Contemporary, Детская хореография, Стретчинг и акробатика, Hip-Hop).
4. **Интерактивная галерея со сцены с Lightbox:**
   - 8 реальных полноразмерных фото постановок ансамбля («Невозможное возможно», KAZAKHSTAN DANCE CODE и др.).
   - Фильтрация по категориям («Все», «Сцена», «Награды», «Команда») и полноэкранный просмотр по клику.
5. **Интерактивный переключатель филиалов:**
   - В один клик переключается между **ул. Таттимбета, 10/5** и **мкр. Степной-4, 30 (ТД «Алмаз»)**.
   - Ссылка на маршрут в 2GIS, расписание, парковка, карта.
6. **Умная форма бронирования пробного урока:**
   - Таймер обратного отсчета для повышения конверсии.
   - Сбор имени родителя, ребенка, возраста, зала и автоматическое формирование сообщения прямо в WhatsApp на номер `+7 707 779 77 43`.
7. **Встроенный видео-шоурил:**
   - Модальный плеер с сольным концертом и фрагментами репетиций.
8. **Калькулятор и тарифная сетка:**
   - Бесплатный пробный урок 0 ₸, 8 занятий, 12 занятий, Семейный тариф со скидкой 20%.

## 📁 Структура проекта:
```
ast-grand/
├── css/
│   └── style.css          # Премиальные стили, адаптив, анимации
├── js/
│   └── main.js            # Логика квиза, галереи, модалок, таймера, WhatsApp-интеграции
├── images/                # Выкачанные в полном качестве реальные фотографии коллектива
│   ├── logo.jpg
│   ├── trainer-1..5.jpg
│   └── stage-1..8.jpg
├── index.html             # Главная страница
├── open-site.bat          # Быстрый запуск в браузере (двойной клик)
└── start-server.bat       # Локальный веб-сервер на http://localhost:8080
```

## ⚡ Как запустить:
- Просто дважды кликните по `open-site.bat` в папке проекта, либо откройте файл `index.html` в любом браузере!
